## ✨ 功能特性

### 📈 智能波浪识别引擎
- **一键自动识别**：基于自研逻辑分析引擎进行验证，自动识别 **1-5 浪 + ABC 调整浪**
- **多方案推演**：同一段行情可生成多个候选方案，逐一标注**可信度评分**
- **手动选点预测**：在 K 线上依次点击 P0~P4 关键点，逻辑分析引擎推演 3-5-A-B-C 多情景走势
- **时间预测（v2.95+）**：推算未来 3/4/5/C 浪持续时间窗口，图表顶部竖虚线标注 ≈X~Y 根 K 线

- 十字准星实时显示 **OHLCV** 数据，成交量同步展示
- 滚轮缩放 / 拖拽平移 
- **止损止盈自动绘制**：红色虚线 = 止损位（浪2底），绿色虚线 = 止盈位（浪3/浪5顶）
- **趋势线工具**：多锚点射线，4 种颜色循环，支持多条叠加

### 🔍 多周期与批量扫描
- **多周期扫描（推荐）**：自动遍历 30m / 60m / 日K / 周K / 月K 五个周期，逐周期识别并评分，弹窗列出最优周期一键加载

## 📖 使用说明（带标注图解）

下面 7 张图按真实操作流程展示，从主界面到完成一次波浪预测的全过程。

### 1. 主界面总览
左侧是参数面板（股票代码、周期、K线根数、关键参数、趋势方向等），右侧是 K 线图区域。顶部信息框显示当前鼠标悬停 K 线的 OHLCV 数据。

![主界面](docs/screenshots/01-overview.png)

### 2. 输入股票代码
在「股票代码」输入框输入代码（沪市以 `sh` 开头如 `sh600519`，深市以 `sz` 开头如 `sz000001`），按回车确认。

![输入股票代码](docs/screenshots/02-input-code.png)

### 3. 点击「获取K线」加载历史数据
点击「获取K线」按钮，程序从网络拉取指定股票/商品的 K 线数据，加载完成后右侧图表自动显示。

![点击获取K线](docs/screenshots/03-fetch-kline.png)

### 4. 鼠标悬停 + 手动选点
- **鼠标悬停**：移到任一根 K 线上，顶部信息框实时显示该日（分钟）的开盘/最高/最低/收盘/成交量
- **手动选点**：根据 K 线图左下方提示，在图上依次点击**起点 P0**（限制最低点）、**一浪顶 P1**（最高点）、**回调低点 P2** 三个关键点 → 左侧会自动显示对应价格

![选点与悬停](docs/screenshots/04-select-points.png)

### 5. 自动识别波浪 + 多情景预测
完成选点后，点击「自动识别浪型」，系统会根据内置逻辑生成**未来 3 浪、4 浪及 5 浪要走多少根 K 线**的预测，并按「**激涨 / 中性 / 弱势**」三种情景叠加展示。点击「`< 上一方案` / `下一方案 >`」可在多组方案间切换。

![自动识别波浪预测](docs/screenshots/05-wave-forecast.png)

### 6. 调整趋势方向与浪型比例
- 「趋势方向」可选**上涨推动浪 / 下跌推动浪**，以及 5 浪组合形态（1-2-3-4-5 或 A-B-C）
- 「浪型比例」可微调三浪/一浪、五浪/一浪、二浪/三浪、四浪/三浪的比例（黄金分割 0.618 / 0.382 / 0.786 等）

![调整趋势和浪型](docs/screenshots/06-set-trend-ratios.png)

### 7. 底部操作按钮一览
- `▶ 预测走势`（核心按钮，参数就绪后点击）
- `R 恢复默认` / `保存方案` / `趋势线` / `导出截图`
- `全A扫描` / `多周期扫描` / `检查更新` / `导出错误日志`
- `注册激活` / `使用说明`

试用版有 **1 小时**试用时间，确认值得使用后再联系作者购买激活码。

![操作按钮](docs/screenshots/07-action-buttons.png)
